# PHASE 5 — Экология, биосфера и финальный аудит всей биологии

## 0. Назначение задачи

Полностью реализовать последний крупный теоретический блок биологии: **экология + биосфера**, а затем провести **финальный содержательный аудит всей биологии проекта**.

Эта задача должна завершить именно **ядро теории биологии**. После неё в продукте не должно оставаться обязательных тем кодификатора, которые существуют лишь как заголовок, краткая карточка, placeholder, технический контейнер или набор тезисов без объяснения механизма.

После PHASE 5 допустимы дальнейшие работы над банком заданий, режимом по линиям ЕГЭ, пробниками, статистикой, UX и QA, но не должно оставаться ситуации «основную теорию по этой теме ещё надо написать».

# 2. Главный принцип качества

## Запрещено считать урок FULL по формальным метрикам

Нельзя объявлять урок полным только потому, что:

- много символов;
- много блоков;
- есть несколько ключевых слов;
- есть SVG;
- есть вопросы;
- audit-скрипт увидел нужные типы блоков;
- в `THEORY_AUDIT.md` написано `manualContentReview: approved`;
- `contentStatus = verified`.

Автоматические проверки нужны только для целостности.

## Настоящий FULL означает

Ученик, который открывает урок **с нулевыми знаниями**, должен после его изучения уметь:

1. дать определения основным терминам;
2. объяснить механизм процесса;
3. провести причинно-следственную цепочку;
4. отличить близкие понятия;
5. прочитать схему, таблицу, график или эксперимент;
6. распознать типичную ловушку ЕГЭ;
7. перенести знание в незнакомую ситуацию;
8. дать полноценный ответ на сложный вопрос второй части без обращения к другому сайту.

Каждая обязательная тема должна строиться как:

**понятие → механизм → причина → следствие → сравнение → схема/данные → ловушки → применение → практика → разбор**.

- иметь доступное описание в course metadata;
- иметь инструкцию «как читать схему» в уроке, если схема сложная;
- загружаться через текущий media resolver без битого URL.

До завершения задачи программно проверить, что **каждый assetKey реально разрешается в существующий файл**.

# 22. Требования к тексту уроков

- `EGE_REQUIRED`;
- `DEEP_DIVE` как сырой технический маркер;
- `contentStatus`;
- `verified`;
- `placeholder`;
- «механизм крупным планом» как пустой шаблонный заголовок без смысловой необходимости;

- дубли абзацев;
- две одинаковые инструкции подряд.

Внутренние метаданные допустимы в JSON/audit, но не должны попадать ученику.

Текст должен быть нормальным русским учебным объяснением.

# 24.3. Если найден слабый старый урок

# 27. Практический аудит всей биологии

Не требуется в этой задаче довести банк всей биологии до окончательного коммерческого объёма, но проверить:

- нет темы с отличной теорией и полностью пустым practice route;

# 28. Научная точность

Отдельно проверить формулировки, где часто возникают школьные ошибки:

- «организмы приспосабливаются потому что им нужно»;
- энергия «круговоротит» в экосистеме;
- 10% как абсолютный закон;
- устойчивость как полная неизменность;
- «сильнейший выживает» без репродуктивного успеха;
- человек произошёл от современных обезьян;
- линейная лестница антропогенеза;
- происхождение жизни как установленный по всем этапам факт;
- абсолютное деление организмов на «полезных/вредных»;
- путаница кислородного/углеродного циклов;
- путаница нитрификации, фиксации и денитрификации;
- стрелки пищевой цепи;
- роль редуцентов;
- «пищевая цепь = круговорот вещества и энергии одинаково».

Все такие ошибки должны быть устранены.

# 33. Acceptance criteria PHASE 5

PHASE 5 можно считать завершённой только если:

1. Экология и биосфера полностью покрывают обязательный экзаменационный материал.
2. Теория написана с нуля до уровня сложных заданий ЕГЭ.
3. Причинные механизмы объяснены, а не перечислены.
4. Есть сравнения и ловушки.
5. Есть полезные SVG и они реально загружаются.
6. Есть оригинальная практика разных механик.
7. Экологические графики/эксперименты/расчёты покрыты.
8. Нет пустых пользовательских тем.
9. Нет служебного текста в уроках.
10. Нет битых media refs.
11. Выполнен финальный whole-biology audit.
12. Найденные слабые обязательные старые уроки исправлены в этой же задаче.
13. Каждому обязательному пункту FIPI можно сопоставить конкретный урок.
14. Все обязательные команды/tests проходят либо конкретно описано, почему отдельная проверка технически недоступна.
15. После задачи можно обоснованно сказать: **ядро обязательной теории биологии на платформе завершено**.
