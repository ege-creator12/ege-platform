# BEFORE-аудит банка для пробников ЕГЭ по биологии

Дата аудита: 2026-09-06. Источники: `course.json` и реестр `exam-lines.json` (проект ФИПИ ЕГЭ-2027).

## Методика

Пригодным считалось активное для импорта авторское задание со стабильным `key`, валидной `examLine`, непустым ответом и положительным `maxScore`. Проверены уникальность ключей, существование локальных медиа, диапазоны сложности, объяснения и критерии развёрнутых ответов. Counts являются только структурной проверкой, а не заявлением об экспертном качестве формулировок.

## Gaps и решение

* Линия 2 имеет только два задания, линия 1 — три, линии 21 и 27 — по шесть. Это реальный дефицит разнообразия; генератор не скрывает его повторами внутри варианта и аудит выдаёт предупреждение для пула менее трёх.
* Пустых линий, повторяющихся ключей и сломанных ссылок на локальные медиа не найдено. Каждая линия позволяет собрать вариант без дублей, поскольку в варианте нужен один слот линии.
* У развёрнутых заданий банка имеются `scoringPoints` и `commonMistakes`; импорт расширен так, чтобы эти поля не терялись. Они предназначены для self-score после сдачи, не для фиктивной автоматической проверки.
* Массовая шаблонная генерация не выполнялась: существующих 951 оригинальных заданий достаточно для стабильной сборки, а точечное редакционное расширение линии 2 остаётся рекомендацией.
* Семантическое сходство и соответствие официальной сложности требуют периодической экспертной редакционной проверки; скрипт намеренно не объявляет качество хорошим только по counts.
